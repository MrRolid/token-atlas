TOKEN ATLAS — WEB PACKAGE / WEBOVÝ BALÍČEK

EN
1. Extract this ZIP and upload all its contents to one directory on your HTTPS web server. Keep the en/ and downloads/ subdirectories. No PHP, database, build or API key is required.
2. Open index.html through your website URL. For local testing use: python3 -m http.server 8000, then open http://localhost:8000. Do not open through file://.

The default interface and model are English. A previously saved interface language is preserved. Without WebGPU, the explanation automatically collapses after 10 seconds. Click its first row to expand or collapse it; after manual interaction your choice takes priority.

CZ
1. Rozbal ZIP a nahraj celý obsah do jedné složky na HTTPS webu. Zachovej podsložky en/ a downloads/. Není potřeba PHP, databáze, sestavení ani API klíč.
2. Otevři index.html přes adresu webu. Lokálně spusť: python3 -m http.server 8000 a otevři http://localhost:8000. Neotevírej přes file://.

Výchozí rozhraní i model jsou anglické. Uložená volba jazyka se zachová. Vysvětlení chybějícího WebGPU se po 10 sekundách sbalí. Kliknutím na první řádek jej rozbalíš nebo sbalíš; po ručním zásahu má tvoje volba přednost.
